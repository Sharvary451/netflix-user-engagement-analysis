# Netflix User Engagement & Content Recommendation

This project analyzes user interaction dynamics on Netflix using graph-based techniques and proposes content recommendation improvements based on user behavior patterns.

## 🔍 Objectives
- Understand engagement patterns using network analysis
- Identify popular content and user clusters
- Recommend optimizations for user experience and recommendations

## 📊 Tools & Tech
- Python, Pandas, NetworkX
- Gephi (graph visualization)
- Matplotlib, Seaborn

## 📈 Methods
- Bipartite graph construction between users and movies
- Centrality metrics: degree, betweenness, clustering
- Graph visualization and segmentation

## 📌 Results
- Identified high-engagement users and popular content
- Proposed bridge-node targeting for better recommendation spread
- Delivered network visualizations for insight delivery
